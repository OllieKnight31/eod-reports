Google Sheets

Required. Every report is stored as a row in a Google Sheet that you own. You give this system a “service account”, which is a robot Google login that is allowed to write to that one sheet.

How to set this up (about 5 minutes)
  1. Create the sheet. Open a new Google Sheet, give it a name, then copy the address from the browser bar and paste it into Google Sheet link below.
  2. Create a Google Cloud project (free). Open “New project”, name it anything, press Create.
  3. Switch on the Sheets API. Open the Google Sheets API page and press Enable.
  4. Create the service account. Open “Create service account”, give it a name, press Create and continue, then Done (skip the optional steps).
  5. Download its key. In the service accounts list click the one you just made → Keys tab → Add key → Create new key → JSON → Create. A .json file downloads. Open it with a text editor, select everything, copy, and paste it into Service account key below.
  6. Save, then share the sheet. After saving, a green box below shows the service account’s email. In your Google Sheet press Share, paste that email, choose Editor, and send.
  7. Press Test connection. The tabs and column headings are created automatically the first time a report is filed.

Slack

Optional. Reports are posted to Slack as they’re filed, along with the daily scorecard and reminders. Everything is already formatted. You create a small Slack app once and paste its token here.

How to get your Slack bot token (about 3 minutes)
  1. Open “Create a Slack app” → choose From scratch → name it (e.g. “EOD Reports”) → pick your workspace → Create App.
  2. In the left menu open OAuth & Permissions. Scroll to Scopes → Bot Token Scopes and add these four: chat:write chat:write.public channels:read groups:read
  3. Scroll back up and press Install to Workspace → Allow.
  4. Copy the Bot User OAuth Token (it starts with xoxb-) and paste it into Bot token below. Press Save Slack.
  5. Press Connect & load channels. The four boxes turn into lists of your real channels. Pick where each report should go, then Save Slack again.
  6. Press Send test messages and check each channel.

Private channel? In that channel type /invite @your-app-name first, or the app can’t post there.

Prefer webhooks? Use one web address per channel instead of a bot token

What is a webhook? A private web address that posts into one specific channel. Anyone with the address can post there, so treat it like a password.

  1. Open your Slack apps and pick your app (or create one as above; webhooks need no scopes).
  2. Left menu → Incoming Webhooks → switch it On.
  3. Press Add New Webhook to Workspace → choose the channel → Allow. Copy the Webhook URL (starts with https://hooks.slack.com/).
  4. Paste it in the matching box below. Repeat for each channel you want.

Discord

Optional. Same as Slack, for a Discord server. The quickest route is a webhook per channel, which is a private web address that posts into that one channel.

How to get a Discord webhook (about 1 minute per channel)
  1. In Discord, hover the channel you want reports in and click the cog (Edit Channel). You need the “Manage Webhooks” permission.
  2. Open Integrations → Webhooks → New Webhook.
  3. Name it (e.g. “EOD Reports”), then press Copy Webhook URL. It starts with https://discord.com/api/webhooks/.
  4. Paste it in the matching box below. Repeat for each channel. You can reuse one channel for several reports by pasting the same address.
  5. Press Save Discord, then Send test messages.

Treat a webhook address like a password: anyone who has it can post in that channel.

Prefer a bot? Use one bot token and pick channels from a list
  1. Open the Discord Developer Portal → New Application → name it → Create.
  2. Left menu → Bot → Reset Token → copy the token and paste it into Bot token below.
  3. Left menu → OAuth2 → URL Generator → tick bot, then tick View Channels, Send Messages and Embed Links. Open the generated link and add the bot to your server.
  4. Press Save Discord, then Connect & load channels, pick a channel for each report, and save again.

Team

Who files reports. Adding names turns the name box on each report into a pick-list, so one person never shows up under three spellings. It is also who reminders chase. Names are saved as soon as you add or remove them.

Optional: make reminders @mention people

A reminder only notifies someone if it has their member ID. Paste it in the “ID” box next to their name.

  1. Slack: click the person’s profile → the ⋮ More button → Copy member ID. It looks like U01ABC2345.
  2. Discord: turn on User Settings → Advanced → Developer Mode, then right-click the person → Copy User ID. It’s a long number.

Using both Slack and Discord? Put both IDs in the box, separated by a comma. Untick “Remind” for anyone who should be on the list but never chased.

Logins

Who can sign in, and what they see. You are the owner: the only login that can open Settings. Give everyone else their own login below.

Manager: sees every dashboard and scorecard and can file any report. No access to Settings.

Setter, Dialler, Closer: sees only Submit EOD, with only their own report, and their own scorecard. Their name is filled in for them.

Targets

What each person should hit in a day. Team targets are worked out from these (target × people × days). On the scorecard every number is shown against its target: On target when it’s met, Below when within 30% of it, Critical when further off. Enter 0 to switch a target off.

Reminders & daily scorecard

Two automatic messages. Both go to the Slack or Discord channels you connected above, at the time you choose here (in your timezone, set under Branding).

CRM

Optional. Connect your CRM to show your live sales pipeline on the EOD Deep Dive page.

How to get your GoHighLevel token and location ID
  1. Open GoHighLevel and switch into the sub-account (location) your sales team uses.
  2. Go to Settings → Private Integrations → Create new integration.
  3. Tick these scopes: View Contacts, Edit Contacts, View Opportunities, Edit Opportunities, View Pipelines (in the list they appear as contacts.readonly contacts.write opportunities.readonly opportunities.write, plus the pipelines read scope).
  4. Create it and copy the token (starts with pit-) into the box above.
  5. For the location ID, look at the address bar while inside the sub-account: app.gohighlevel.com/v2/location/THIS-PART/…. You can paste the whole address.
  6. Press Save CRM, then Connect & load pipelines, choose your pipeline, and match each column to a stage.

With GoHighLevel connected, logging a call outcome on the closer report also moves that prospect’s opportunity to the matching stage.

How to get your Close API key
  1. Open Close → Settings → Developer → API Keys.
  2. Press New API Key, name it (e.g. “EOD Reports”), and copy the key (starts with api_). Close only shows it once.
  3. Paste it above, press Save CRM, then Connect & load pipelines, choose your pipeline, and match each column to one of its statuses.

Close is read-only here: it shows your pipeline on the dashboard. Call outcomes logged on the closer report are not written back to Close.

Match each dashboard column to a stage in that pipeline. Leave a column on “Not used” to hide it.

Mechanisms

How leads reach you: webinar, DMs, a lead magnet and so on. These are the choices on the reports and the breakdown on the Overview and EOD Deep Dive pages. Add yours, remove the ones you don’t use. Changes save straight away.

Removing a mechanism doesn’t delete past reports. Old rows that used it are counted under the first mechanism in the list.
